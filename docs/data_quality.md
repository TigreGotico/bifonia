# Data quality control

The corpus is synthetic: sentences are generated by coding-agent CLIs with one intended sense each, and a line is admitted only when the rule engine agrees with the intended label. Because the rule engine *assigned* the labels, it cannot serve as a self-check. QC therefore uses signals **independent** of the rule engine and reviews only the lines where those signals disagree with the stored label. This review is far cheaper than reading the whole corpus, and it is where real errors concentrate.

## Method

1. **Multi-signal prediction.** Each line is independently re-labelled by signals that do not derive from the rule engine: a spaCy POS tagger mapped to sense (`pt_core_news_lg`), the Naive-Bayes model, and the averaged-perceptron model.
2. **Disagreement flagging.** A line is flagged when an independent signal contradicts the stored label. spaCy alone flags a large fraction (around a third), dominated by its own POS errors on minority (verb) readings, since the corpus is balanced 50/50 while spaCy is noun-biased. The high-precision signal is **both trained models disagreeing** with the label.
3. **Stratified adjudication.** A native-Portuguese LLM agent judges each flagged sentence's sense *blind to the stored label*. Adjudicate the full both-models-disagree stratum, plus random control samples from the spaCy-only bucket and the all-agree bucket, to estimate baseline error rates.

## What the signal detects

The both-models-disagree stratum carries roughly 30% real-label-error precision, against a baseline of about 1.3% in the all-agree bucket. This is a large enrichment. Errors are systematic rather than random and concentrate in a few confusable pairs, for example `forma: shape↔mould` (baking-tin/casting *fôrma*, closed-o `ˈfoɾmɐ`, mislabelled as the open-o "shape" reading), `sede: seat↔thirst`, and `molho: bundle↔sauce`.

Adjudicated disagreements are resolved by relabelling the line to the verified sense, or dropping it when the target word is used in a sense outside the roster.

**Residual check.** After resolving the flagged set, re-adjudicate a fresh sample of lines from the most-contaminated label that were *not* in the original sample. A low residual contamination rate confirms the disagreement stratum had isolated the systematic errors.

## Estimated corpus quality

With the model-flagged stratum cleaned, the bulk all-methods-agree lines and the spaCy-only-flagged bucket each run around 98 to 99% correct, giving overall label accuracy near 98.5% and the dominant systematic error class removed.

Reproduce: `qc_phase1.py` performs the flagging. The per-stratum sampling and agent adjudication follow the procedure above, and re-run on any corpus revision.

## Out-of-fold model signal (all words)

spaCy only helps POS-separable words and is noun-biased. For an independent signal that **covers every word**, including same-POS pairs and words the per-word models were not trained on, re-score the corpus **out-of-fold**: a 5-fold split per word, each line predicted by NB+perceptron trained on the *other* folds. Because no line is in its own training fold, the prediction is independent of that line's stored label.

Both OOF models disagree with the label on roughly 0.5% of lines. Agent adjudication of the flagged set (deduped against the spaCy/in-fold pass) detects the same systematic sense confusions (for example `sede` thirst↔seat blocks, `forma` shape↔mould), plus **generation-artifact lines**: agent chatter, file logs, and English prompt echoes that leaked in as "sentences" (for example ``Ficheiro `frases_x.txt` com 40 frases``). Artifacts are identified by markers absent from natural sentences: backticks, `.txt`/`.jsonl` references, "N frases", and "como verbo/substantivo". Adjudicated lines are relabelled, dropped (defective), or swept (artifacts).

Reproduce: `oof_qc.py`.
